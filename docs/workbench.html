05 / HYPOTHESIS SELECTION

Weakest or shortest?

A finite supervised learning experiment inspired by Bennett. A hidden two-bit rule mask labels possible one-step transitions. Find every rule set consistent with the training labels, then compare largest extension against smallest rule count on untouched pairs.

Consistent hypotheses
Weakest test accuracy
Shortest test accuracy
Held-out pairs

Run a seeded benchmark across independent target masks and splits.

Extension = number of accepted pairs in the finite universe. Code length proxy = count of active primitive rules (fixed cost per rule); tie break by smallest mask. Neither is a universal inductive prior. The held-out pairs come from the same finite domain, not new worlds.
