# Research 014 — Finite rule-space workbench
## Scope
All asynchronous, length-preserving binary rules with left/right sides of length 1–4, at most 16 distinct rules, and initial word of length 2–8. Every reachable microstate is exhaustively enumerated (at most 256); edges count rule occurrences, including overlapping matches as separate events. No rules change length. No claim of Ruliad completeness, consciousness, spacetime emergence or general computational irreducibility.
## 014-A: Rule atlas and confluence
The twelve ordered nonidentity two-bit replacements have 2^12 subsets. The atlas enumerates all 4,096 on seed 00101. Tarjan SCCs give the condensation DAG. On a finite reachable graph every state reaches a bottom SCC. Every pair of states admits a common descendant iff the condensation DAG has exactly one bottom SCC: if unique, both can reach it and within it any chosen state; if multiple, states in distinct bottom SCCs cannot join. This is confluence restricted to the reachable subgraph; termination is equivalent to absence of directed cycles. Normal forms are states with no outgoing edges. Neither classification extends automatically to all starting words.
## 014-B: Exact observer compiler
A finite Markov chain chooses uniformly among enabled rule occurrences; terminal state is absorbing. Given an observation partition, split each block by the vector of transition probabilities into the current blocks. Fractions are reduced by gcd, compared as canonical integer strings. Continue until stable. Every stable refinement must refine each intermediate partition (induction: equality on finer classes implies equality after summing over coarser classes), so the result is the coarsest strongly lumpable refinement of the initial partition. It is autonomous for all initial distributions under this chosen policy. No interpretation as subjective experience.
## 014-C: Graph spectral geometry
Use the undirected simple graph obtained by discarding orientation and multiplicities, Laplacian L=D−A. Connectedness follows from reachable states; for n>1 exactly one zero eigenvalue. Compute all eigenvalues by numerical Jacobi rotations for at most 64 nodes; report maximum remaining off-diagonal magnitude and check trace=2|E|. This residual is a diagnostic, not an interval certificate. Heat trace Z(t)=sum exp(−t λ), running dimension 2t sum λ exp(−tλ)/Z. On finite graphs it tends to zero as t→0 and t→∞. No claim of manifold limit. The graph metric is a modeling choice.
## 014-D: A finite learning comparison
On all 32 five-bit words, construct all ordered source/target pairs reachable by one primitive two-bit replacement. For each pair precompute the bitmask of all primitive rules producing it. A hypothesis mask accepts the pair iff the masks intersect. A hidden mask produces labels, and a seeded Fisher–Yates shuffle defines disjoint training and test pairs. Enumerate all 4,096 masks consistent with training. Weakness proxy maximizes extension cardinality over the full unlabeled pair universe; shortest proxy minimizes number of active rules, a fixed-cost-per-rule description. Tie break by smallest integer mask. Report held-out pair accuracy; candidate choice uses no test labels. This is a deliberately finite analogue inspired by Bennett, not Stack Theory or a proof of optimal generalization. The test universe shares the same word length; future tests should split by source words or tasks, vary coding priors and report distributions over many target masks and seeds.
## 014-E: Reproducibility
The notebook exports configuration plus graph, classifications, observer partition, spectrum and candidate statistics. Import validates a fixed schema and recomputes results. Shareable URLs encode only configuration. All computation happens locally; no arbitrary code execution, external scripts or account data.
