# Research 017 — Conjecture Commons
Inspired by Gowers' [Polymath proposal](https://gowers.wordpress.com/2009/01/27/is-massively-collaborative-mathematics-possible/) and [Massively collaborative mathematics](https://doi.org/10.1038/461879a).

A proposition is an implication with a conjunction of at most six numeric predicates and one conclusion. The domains are all 4,096 subsets of the twelve nonidentity two-bit rules on seed 00101, or all 256 three-bit Boolean sign functions. The enumerator is deterministic, and returns eligible count, total failures and the first 32 witnesses. A refutation is a counterexample in this precise domain. A finite pass asserts only a bounded exhaustive result; vacuous means no objects satisfy premises. The rule-world joinability criterion is proved in research 014. The U3/U2 comparison rescales U2^8 to the same denominator as U3^8; N=8 means U2 numerator squared divided by 512. This is an exactly represented binary rational. Additive energy inequality follows Cauchy–Schwarz. The certificate is a versioned JSON object with the full conjecture and search result. Import recomputes, not trusts, the result. It does not authenticate an author or replace peer review.
 
Collaboration: use an issue for a proposition, finite domain, certificate and next proof obligation; attach full JSON when the prefilled summary is truncated. Cite independent counterexamples and distinguish a formal proof from computational evidence. No server, automatic publication or arbitrary code execution. Share links contain the conjecture, not user credentials.
